How I approach it

No fixed formula yet — but a few habits I try to keep as I learn.

01

Curiosity first

I follow the question that's actually bothering me, then go looking for the research or reading that answers it, rather than working strictly top-down from a syllabus.

02

Build to understand

Reading about a concept only gets me so far — I try to implement a small version of it myself before I trust that I actually understand it.

03

Learn in public

Keeping notes and code on GitHub as I go, even when it's unfinished, so progress is visible and easy to revisit later.

04

Ask early, ask often

As a research assistant, I've learned that a well-timed question saves more time than pretending to already know the answer.
